## Known deficiencies and required independent review

1. **No actual Terraform, application or Playwright application source.** Some commands may require version-specific flags, property names or data-plane roles, and the authentication/session tests `AZ-T64-05` and `AZ-T64-15` remain unimplemented in an actual application.
2. **Configuration ≠ proof of isolation.** A public-access flag alone cannot prove absence of alternate ingress; corroborate from approved resource inventory, actual DNS/private IP mapping, and independent external vantage point.
3. **HTTP 403, NXDOMAIN or timeout ≠ safe private connectivity.** Classification Step 63 explicitly treats missing provisioning or uncorroborated denial as NOT_READY.
4. **WAF simulation requires explicit non-production authorization.** Step 69–70 request commands are not run automatically, and WAF `Matched` does not equal `Blocked`.
5. **Synthetic rules are simplified.** Several fixture comparators are illustrative booleans or approved strings, and do not exhaustively establish the full natural-language security criterion.
6. **Plan-policy guard is intentionally narrow.** It recognizes only selected public-access and NSG patterns; unknown resource types and absent values must be independently evaluated before acceptance.
7. **Performance and DR cannot be approved offline.** RPS, p95, recovery targets, retry boundedness, time-based log collection and cross-layer correlation need actual measured evidence.
8. **Source code upload to a public repository is not an authorization to publish credentials or sensitive operations data.** Keep secrets and actual environment identifiers outside this repository.
