JSON fields are `as_of` (ISO date) and `workspace_id`; optional observations are `app_insights` (workspace_id), `query_role` (scope_id, principal_id, approved_principal_id, role_guid, approved_role_guid), `public_exceptions` (list with owner, purpose, scope, expires), and `absence_alert` (workspace_id, enabled, checks_absence, action_group_id, approved_action_group_id). Compare only approved extracts. MATCHED_OFFLINE denotes agreement with the supplied baseline; effective permissions, register completeness, rule firing and message delivery require separate evidence.
